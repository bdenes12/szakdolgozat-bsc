PostgreSQL Anonymizer — csak a nézetben (dev_export) használható,
szignatúra alapján kezelhető függvények.

Szűrés:
- kiesett: boolean / TABLE / event_trigger (init, anonymize_*, mask_*, load, detect, …)
- kiesett: SQL segédfüggvény névtelen text argumentummal (md5, lower, substr, to_char, …)
- kiesett: dummy színek, buzzword, isbn, ip, user_agent stb. (nem kellenek a demóhoz)

Oszlop: I = az első argumentum a maszkolandó oszlop értéke
        N = nincs oszlop, a parameters JSON tölti az argumentumokat
        (0 arg esetén a JSON [])
